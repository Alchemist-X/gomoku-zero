The run warm-started from the generation-pinned online model, trained four
iterations of 16 self-play games at 800 MCTS simulations per move, and froze
every iteration checkpoint. It then ran all five fixed models in an 80-game
round robin at 128 simulations per move.

Each matchup used four independently seeded opening pairs. A random coin flip
selected the first color assignment, followed by an exact color swap on the
same opening. Every model pair therefore played four games as Black and four as
White.

## Elo

small and the intervals are wide. This pilot is not sufficient for a formal
promotion claim.

The lowest training loss was v0003, while the highest Elo point estimates were
v0001 and v0002. This is direct evidence that training loss alone is not a safe
model-selection criterion.

Self-play inference reached roughly 1,100–1,460 positions/s on the A100, but
end-to-end throughput was only 592–692 positions/s. The remaining bottleneck is
mostly the single-process Python PUCT/control path rather than neural inference.

The round robin completed in 625 seconds (460.7 games/hour) with an average of
56.0 plies per game.
